# 💰 Advanced Expense Tracker App

A modern and professional Expense Tracker Dashboard built using Python and Streamlit.

---

# 🚀 Features

## 🔐 Authentication System

* User Registration
* Secure Login
* Password Hashing using bcrypt
* Multi-user support

## 💵 Expense Management

* Add Expenses
* Edit Expenses
* Delete Expenses
* Search Expenses
* Filter by Category

## 📊 Analytics Dashboard

* Pie Charts
* Bar Charts
* Daily Expense Trend
* Total Expense Calculation
* Average Expense Tracking
* Budget Progress Bar

## 📂 File Features

* CSV Upload
* Excel Export

## 🎨 Modern UI

* Glassmorphism Design
* Dark Theme
* Gradient Buttons
* Responsive Dashboard
* Interactive Charts

---

# 🛠 Technologies Used

* Python
* Streamlit
* SQLite
* Pandas
* Plotly
* OpenPyXL
* bcrypt

# ⚙ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/expense-tracker-app.git
```

---

## 2️⃣ Open Project Folder

```bash
cd expense-tracker-app
```

---

## 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

---

## 4️⃣ Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

---

## 5️⃣ Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶ Run Project

```bash
streamlit run app.py
```
